# Irhamhuma (رَّبِّ ارْحَمْهُمَا) — Open-Source Family Care & Routine Reminder Calls

> *"Rabbi irhamhuma kama rabbayani saghira"* — "My Lord, have mercy upon them as they brought me up when I was small." (Quran 17:24)

**Irhamhuma** is an open-source, self-hosted family care and daily routine reminder system for developers supporting aging parents back home.

## Why I Built This (The Story)

When my father (**Abbu**) in Pakistan was discharged from the hospital, his recovery depended on a strict daily routine of meals, hydration, and post-meal routines managed on the ground by my mother (**Ammi**), while I lived abroad in Sweden.

Simple phone alarms failed immediately:
1. **Passive alarms get dismissed**: If Ammi was in the kitchen or Abbu asked for 10 minutes, an alarm was swiped away and forgotten.
2. **Meal-dependent timing (`AFTER_TASK`)**: Many items are chained to meals (*15 minutes after Breakfast*, *2 hours after Breakfast*, *15 minutes after Dinner*). Fixed-time alarms break whenever breakfast shifts by 45 minutes.
3. **Reluctance & Caregiver Fatigue**: Sometimes Abbu refused a meal or routine, and Ammi needed backup from me right away without having to dial abroad and explain the context.

I built **Irhamhuma** so that at each scheduled task time:
- **Step 1 (Minute 0 — WhatsApp or Telegram + Native Urdu Voice Note)**: Sends a written summary card + a natural Pakistani Urdu voice note (`ur-PK-Standard-A` / `ur-IN-Wavenet-A`) on **WhatsApp** (for regions where Telegram is restricted, such as Pakistan) or **Telegram Bot** (`$0.00` free with 1-tap inline buttons). Replying **`1`** (or tapping Done) marks the task completed, unlocks any chained `AFTER_TASK` items (`+15m`, `+120m`), and sends a silent `✅ Done` confirmation to the family member abroad on Telegram.
- **Step 2 (Minute 5 — Direct Call to Caregiver)**: If unconfirmed after 5 minutes, calls the caregiver (tries a Twilio WhatsApp Voice Call first with automatic fallback to a PSTN cellular call speaking native Urdu `<Play>` with keypad confirmation `1` Done, `2` Snooze, `3` Escalate).
- **Step 3 (Escalation + Press-9 Live Bridge)**: Only if the caregiver misses both call attempts (or presses/replies `3`), sends an Escalation Alert to the family member abroad (on Telegram +/or WhatsApp) and places an Escalation Phone Call where pressing **`9`** bridges the call live (`<Dial>`) directly to home.

## Security Architecture (Built-In)

Because Cloud Functions URLs are public on the internet, Irhamhuma enforces three layers of protection against toll fraud and unauthorized access:
1. **Twilio Webhook Signature Validation (`twilio.validateRequest`)**: Every Twilio webhook (`/whatsapp-webhook`, `/caregiver`, `/caregiver-gather`, `/escalation`, `/escalation-gather`, `/status`) verifies the cryptographic `X-Twilio-Signature` header using your `TWILIO_AUTH_TOKEN`. Unsigned requests are rejected with `403 Forbidden`.
2. **Dashboard Passcode Authentication (`x-irhamhuma-key`)**: `/sync-state` and all `/trigger-*` endpoints require your secret `DASHBOARD_API_KEY` header verified via constant-time `crypto.timingSafeEqual`. The passcode is entered once in the browser UI (stored in `localStorage`) and is never embedded in the JavaScript bundle.
3. **Country-Code Prefix Allowlist (`ALLOWED_CALL_PREFIXES`)**: Outbound Twilio calls and `<Dial>` bridges only dial numbers matching your configured country prefixes (e.g., `+92,+46`) and only dial the authoritative phone numbers stored in Firestore `settings/careConfig`.

## Self-Hosting Deployment Guide

### Prerequisites
1. **Node.js 22+** and **Firebase CLI** (`npm install -g firebase-tools`).
2. **Firebase Project** upgraded to the **Blaze (Pay-as-you-go) Plan** (required for Cloud Functions, Cloud Scheduler, and Google Cloud Text-to-Speech API).
   - Enable **Firestore Database**, **Cloud Functions**, **Cloud Scheduler**, and **Cloud Text-to-Speech API** in the Google Cloud Console.
3. **Telegram Bot ($0.00 Free Messaging & Escalation Updates)**:
   - Message **[@BotFather](https://t.me/BotFather)** on Telegram $\rightarrow$ `/newbot` to get a `TELEGRAM_BOT_TOKEN`.
   - Can be used for **both** Caregiver and Escalation Contact in countries where Telegram is unblocked, or paired with **WhatsApp** for the Caregiver in countries where Telegram is restricted (such as Pakistan).
4. **Twilio Account** (for PSTN Voice Call fallback, Press-9 Live Call Bridging, and WhatsApp where Telegram is restricted):
   - Buy a Twilio phone number with Voice + SMS/WhatsApp capabilities.
   - *(If using WhatsApp)* Register your Twilio number as a **WhatsApp Business Sender** in the Twilio Console (*Messaging -> Senders -> WhatsApp senders*).
   - Enable **Voice Geographic Permissions** for your target countries (e.g., Pakistan `+92`, India `+91`, Sweden `+46`).
5. **Gemini API Key** from [Google AI Studio](https://aistudio.google.com/) (for the optional natural-language schedule builder).

### Step-by-Step Setup

```bash
# 1. Clone the repository & install dependencies
git clone https://github.com/AhsanAyaz/irhamhuma.git
cd irhamhuma
npm install
cd functions && npm install && cd ..

# 2. Configure your Firebase project ID
cp .firebaserc.example .firebaserc
# Edit .firebaserc and set "default" to your Firebase project ID

# 3. Configure backend environment variables
cp .env.example functions/.env
# Edit functions/.env with your TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN,
# TWILIO_PHONE_NUMBER, GEMINI_API_KEY, DASHBOARD_API_KEY, and ALLOWED_CALL_PREFIXES

# 4. Build Cloud Functions and Angular Web App
cd functions && npm run build && cd ..
npm run build

# 5. Deploy to Firebase Hosting & Cloud Functions
firebase deploy
```

### Post-Deploy Configuration
1. Open your deployed web app (`https://<your-project>.web.app`).
2. Enter your `DASHBOARD_API_KEY` passcode in the top **🔒 Family Passcode** bar to unlock Cloud Sync.
3. Go to **⚙️ Settings**:
   - Configure your family titles (e.g., *Abbu*, *Ammi*, *Your Name*), phone numbers, and preferred TTS voice (`ur-PK-Standard-A` for Urdu, `hi-IN-Wavenet-A` for Hindi, `ar-XA-Wavenet-A` for Arabic, `bn-IN-Wavenet-A` for Bengali, or `en-US-Wavenet-F` for English).
   - Select the **Caregiver Messaging Channel** (`WhatsApp`, `Telegram`, or `Both`) and **Escalation Notification Channel** (`Telegram` recommended — $0.00 & no 24-hour window restriction).
   - Paste your `@BotFather` **Telegram Bot Token** and click **Save Configuration** (this automatically registers `/twimlRouter/telegram-webhook` with Telegram).
   - Send `/start` to your bot on Telegram — it will reply with your numeric **Chat ID**, which you paste into Settings and save.
4. *(If using WhatsApp)* In the **Twilio Console** (*Messaging -> Senders -> WhatsApp senders*), set the **Webhook URL for incoming messages** (HTTP `POST`) to:
   ```text
   https://us-central1-<your-firebase-project-id>.cloudfunctions.net/twimlRouter/whatsapp-webhook
   ```
